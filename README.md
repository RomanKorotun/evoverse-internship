Evoverse Internship homework-3

## Завдання

Написати веб-сервер (на Express) для завантаження великих файлів частками, передбачити інтерфейс списку завантажених файлів, просмотр файлу, видалення файлу, статус виконання завантаження. Додати ліміт (квоту) на файлове сховище, який встановлюється додатковим роутом

## 1. Загальні положення

1.1. Спочатку потрібно клонувати репозиторій на свій локальний комп'ютер

```bash
git clone url-репозиторія
```

1.2. Запустити Docker

1.3. Відкрийте термінал у корені проєкту та виконайте команду. Ця команда збирає образи і запускає контейнери у фоновому режимі.

```bash
 docker compose up --build -d
```

## 2. BACKEND

2.1. Заходимо в контейнер. Тут node_app_hw_3 — назва контейнера з docker-compose.yml.

```bash
 docker exec -it node_app_hw_3 sh
```

2.3. Порт сервера

- За замовчуванням сервер працює на порту **3030**.
- Порт можна змінити у файлі: backend/src/server.js

  2.5. API маршрути

- `POST /files` — завантаження файлу частинами
- `POST /files/quota` — встановлення квоти (ліміту) на на розмір файлового сховища
- `DELETE /files/:filename` — видалення файлу
- `GET /files` — список усіх завантажених файлів
- `GET /files/download/:filename` — скачування конкретного файлу
- `GET /files/:filename` — перегляд конкретного файлу
- `GET /files/stats` — статистика файлового сховища (кількість файлів, використана квота, загальний розмір)

  2.6. API відповіді

Усі значення розміру (sizeBytes, totalSizeBytes, quotaBytes) повертаються у байтах.

- `GET /files`

```json
{
  "files": [
    {
      "name": "file1.jpg",
      "sizeBytes": 78629,
      "createdAt": "2026-03-29T10:05:27.565Z"
    },
    {
      "name": "file2.jpg",
      "sizeBytes": 92427,
      "createdAt": "2026-03-29T10:16:49.058Z"
    }
  ]
}
```

- `GET /files/status`

```json
{
  "totalSizeBytes": 2187746,
  "quotaBytes": 3145728,
  "filesCount": 6
}
```
