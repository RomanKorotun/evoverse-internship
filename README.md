Evoverse Internship homework-3

## Завдання

Написати веб-сервер (на Express) для завантаження великих файлів частками, передбачити інтерфейс списку завантажених файлів, просмотр файлу, видалення файлу, статус виконання завантаження. Додати ліміт (квоту) на файлове сховище, який встановлюється додатковим роутом

## 1. Використані технології

### Backend

- Node.js
- Express.js
- Swagger (OpenAPI) для документації API

### Frontend

- React

### База даних

- Redis

### Інфраструктура

- Docker (Dockerfile, Docker Compose)

## 2. Загальні положення

2.1. Спочатку потрібно клонувати репозиторій на свій локальний комп'ютер

```bash
git clone url-репозиторія
```

2.2. Налаштування середовища

- У корені репозиторію створіть файл **.env**
- Заповніть його змінними середовища на основі прикладу з файлу **.env.example**

2.3. Запустити Docker

2.4. Відкрийте термінал у корені репозиторію та виконайте команду. Ця команда збирає образи і запускає контейнери у фоновому режимі.

```bash
 docker compose up --build -d
```

## 3. BACKEND

3.1. Щоб зайти в контейнер і виконувати команди всередині нього, використовуйте команду нижче. Тут node_app_hw_3 — назва контейнера з docker-compose.yml.

```bash
 docker exec -it node_app_hw_3 sh
```

3.2. API маршрути

- `POST /files` — завантаження файлу частинами
- `POST /files/quota` — встановлення квоти (ліміту) на розмір файлового сховища
- `GET /files/quota` — отримання квоти (ліміту) на розмір файлового сховища
- `PUT /files/quota` — оновлення квоти (ліміту) на розмір файлового сховища
- `DELETE /files/:filename` — видалення файла
- `GET /files` — список усіх завантажених файлів
- `GET /files/download/:filename` — скачування конкретного файла
- `GET /files/:filename` — перегляд конкретного файла
- `GET /files/stats` — статистика файлового сховища (використана квота, загальний розмір завантажених файлів, кількість завантажених файлів)

3.3. Swagger документація

- `/swagger` — відкриває свагер документацію

Тут можна переглянути всі доступні маршрути, їх параметри та приклади відповідей.

3.4. API відповіді

Усі значення розміру (sizeBytes, totalSizeBytes, quotaBytes) повертаються у байтах.
